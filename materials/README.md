# Research Materials

This directory groups research inputs separately from active presentation code.
Paths referenced by `sources.yml` are checksum-protected.

## Access classes

- `manuscripts/`: internal primary source documents.
- `research-notes/`: internal notes and supporting media; never embed directly.
- `references/`: internal supplied references.
- `derived/`: restricted or internal extracts used by validators and claims.

Do not add raw participant data. Public release media belongs in
`src/assets/images/` and uses anonymous stable asset IDs. Moving a registered
source requires updating its path without changing its stable source ID; update
the checksum only when the file content intentionally changes.
