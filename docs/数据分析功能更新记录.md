# 数据分析功能更新记录

更新日期：2026-05-27  
适用范围：实验结束后的眼动数据导入、单个数据分析、整体数据分析、异常数据筛查与坐标修正预览。

## 1. 更新背景

本次更新围绕 `data523` 文件夹中的既有实验数据展开。实验工具已经完成主要采集阶段，因此新增功能重点从“实时追踪”转向“实验后数据分析”：

- 兼容之前已经保存的 JSON 数据文件。
- 支持一次性导入多个实验记录或整个数据文件夹。
- 按实验设计重新确认分组：`a1`、`b1` 为对照组，`a2`、`b2` 为实验组。
- 对可能受追踪偏移、局部压缩、边缘裁切等问题影响的数据进行筛查。
- 在不破坏原始数据的前提下，提供坐标修正和热力图重映射预览。
- 优化单个数据分析界面，使切换参与者后可以立即看到热力图。

## 2. 数据导入功能

### 2.1 多文件导入

新增多 JSON 文件导入能力。用户可以一次选择多个历史实验记录文件，系统会自动解析并合并到当前分析列表中。

### 2.2 文件夹导入

新增文件夹导入入口，适用于直接选择 `data523` 这类实验数据文件夹。系统会读取其中的 JSON 记录，并跳过非实验数据文件。

### 2.3 旧数据兼容

导入过程继续使用兼容层处理历史保存格式。对于旧版本保存的数据，系统会尽量补全当前分析模块需要的字段，避免旧数据因为字段差异而无法进入分析流程。

同时，本次更新加入了重复记录处理机制。若导入的文件中存在相同参与者或相同实验记录 ID，系统会自动生成唯一标识，避免切换参与者或记录时选中错误数据。

## 3. 实验分组规则

本次更新将分组规则固定为：

| 图片/条件 | 分组 |
| --- | --- |
| `a1` | 对照组 |
| `b1` | 对照组 |
| `a2` | 实验组 |
| `b2` | 实验组 |

分析时优先根据图片编号或图片名称判断分组，而不是完全依赖旧 JSON 中保存的条件标签。这样可以修正旧数据里可能存在的标签不一致问题。

## 4. 页面结构调整

报告页面被拆分为两个主要分析页面：

- 单个数据分析
- 整体数据分析

### 4.1 单个数据分析页面

单个数据分析页面现在采用更紧凑的布局：

- 参与者列表、追踪记录列表和当前记录信息集中在顶部。
- 热力图和轨迹图区域直接放在选择区下方。
- 切换参与者或追踪记录后，可以在首屏范围内快速看到对应热力图。
- 原先占用首屏空间的统计卡片在单个分析模式下隐藏，避免把热力图挤到页面下方。

### 4.2 整体数据分析页面

整体数据分析页面集中展示跨参与者、跨条件的汇总结果，包括整体指标、分组对比、图片对比、区域分布和异常数据摘要。

## 5. 单个数据分析功能

单个记录分析中保留并强化了以下功能：

- 当前参与者和当前追踪记录快速切换。
- 热力图查看。
- 注视轨迹图查看。
- 时间范围筛选。
- 是否显示背景图片。
- 轨迹播放。
- 透明热力图图层导出。

这些功能主要用于检查某一次实验记录中，参与者注视区域、追踪点分布、时间顺序和背景图片之间的关系。

## 6. 整体数据分析功能

整体分析面向全部导入数据，新增以下统计内容：

- 参与者数量。
- 追踪记录数量。
- 采样点总数。
- 有效点比例。
- 平均采样率。
- 疑似技术异常数量。
- 实验组与对照组对比。
- 不同图片之间的指标对比。
- A4 画面九宫格区域注视分布。
- 自动文字摘要。

整体分析结果可以导出为 CSV 或 JSON，方便后续进入 Excel、统计软件或论文整理流程。

## 7. 异常数据筛查

考虑到本实验中的追踪结果可能受到摄像头、姿势、校准质量、网页坐标映射等因素影响，本次更新加入了异常数据筛查模块。

### 7.1 当前判定为技术异常的情况

系统目前主要筛查以下几类较明确的技术异常：

| 类型 | 含义 |
| --- | --- |
| 记录过短 | 采样点数量或记录时长明显不足，难以支撑分析 |
| 有效点比例过低 | 大量追踪点落在 A4 分析区域之外 |
| 边缘裁切 | 大量点集中在画布边缘，可能是坐标被裁切或限制 |
| 严重偏移 | 点云整体明显偏离主体画面，同时覆盖范围较小 |

### 7.2 不再直接判定为异常的情况

本次根据实验实际情况收紧了异常判定。以下情况不再默认作为异常：

- 参与者只看了画面中的部分区域。
- 追踪点集中在某一个内容区域。
- 热力图没有覆盖整张 A4 图片。
- 存在轻微整体偏移，但仍能反映注视区域。

原因是本实验本身不要求参与者完整扫视整张图片。不同参与者关注不同内容是合理现象，不能简单地把“覆盖范围小”当成坏数据。

### 7.3 观察提示

对于“局部集中”“轻微偏移”等情况，系统会更倾向于作为观察提示展示，而不是直接计入疑似异常数量。这样可以减少误报，更符合实验数据的实际解释需求。

## 8. 坐标修正与热力图重映射

为处理追踪区域偏移、坐标压缩等问题，单个数据分析中新增坐标修正预览功能。

### 8.1 修正模式

| 模式 | 说明 |
| --- | --- |
| 原始 | 使用原始保存坐标绘制 |
| 中心平移 | 将整体点云移动到画面中心附近 |
| 范围拉伸 | 根据点云范围重新拉伸到分析画布 |
| 自动 | 根据异常类型自动选择较保守的修正方式 |

### 8.2 修正原则

坐标修正只影响当前热力图、轨迹图和透明图层导出，不会覆盖或改写原始 JSON 数据。

这意味着用户可以对比原始结果和修正预览结果，并在最终分析中自行决定是否采用修正后的解释。

## 9. 导出功能

本次更新后，分析导出内容包括：

- 整体分析 CSV。
- 整体分析 JSON。
- 单个记录透明热力图图层。
- 当前导入数据的兼容分析结果。

CSV 适合表格软件查看和人工整理；JSON 适合继续进行程序化分析或保存完整结构。

本次更新过程中已经完成以下检查：

- `app.js` 语法检查。
- 代码空白和补丁格式检查。
- 页面 DOM 引用检查。
- 本地浏览器加载检查。
- `data523` 历史数据解析检查。
- 实验组/对照组分组结果检查。

## 11. 后续建议

后续如果继续完善，可以考虑增加以下能力：

- 将异常记录和修正预览结果单独导出为审查表。
- 给每条异常记录增加人工确认状态，例如“保留”“剔除”“采用修正后版本”。
- 增加修正前后对比图，便于论文或报告中说明数据处理过程。
- 对同一参与者的重复导入记录进行更明确的合并或去重策略。
- 增加按实验组、对照组自动生成统计图表的功能。
