# Style Exceptions

The migrated visual baseline contains legacy `!important` declarations. They are
temporarily accepted only inside the six CSS modules generated by
`scripts/migrate-css.mjs`; the migration check prevents silent drift. New
`!important` declarations are not approved unless recorded below.

Any future `!important`, non-token value, or language-specific geometry override must record:

- stable layout or component ID;
- exact selector and property;
- reason the normal cascade or token cannot express the requirement;
- affected slide and language IDs;
- regression test and removal condition;
- approval date and reviewer.

An undocumented exception fails the CSS audit.
